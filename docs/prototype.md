# Initial product prototype

The prototype demonstrates a data operations workflow:

**Buyer brief → collection → quality review → delivery.**

It includes an editable brief, a searchable review queue, per-episode notes and decisions, recapture requests, a rights-hold gate, task coverage totals, and a JSON delivery manifest.

## Scope

All sample episodes, contributor identities, durations, scores, and rights references are synthetic. The sample represents human video. Changing a planned capture modality does not turn those records into robot-action data.

The prototype has no real recordings, hardware integrations, signed permissions, actual customers, shared backend, or model evaluations. Its state is stored locally in the viewer's browser and is not a secure production data store.

Internal demo acceptance is not buyer acceptance or evidence of model improvement.

## Next milestone

Connect one real pilot: sample upload and playback, shared episode metadata and verified permission records, authenticated reviewer roles, and an export validated against a buyer's importer. Add synchronization and robot-action schemas only where the selected capture setup supplies those signals.
