# Offline workflow demo — v0.1 (6 October 2026)

This document describes the demo software, not the status of Kinefoundry’s managed data collection service. For buyer and supplier enquiries, visit [kinefoundry.com](https://kinefoundry.com/).

The demo illustrates a data operations workflow:

**Buyer brief → collection → quality review → delivery.**

It includes an editable brief, a searchable review queue, per-episode notes and decisions, recapture requests, a rights-hold gate, task coverage totals, and a JSON delivery manifest.

## Demo scope and limitations

All sample episodes, contributor identities, durations, scores, and rights references are synthetic. The sample represents human video. Changing a planned capture modality does not turn those records into robot-action data.

The demo has no real recordings, hardware integrations, signed permissions, actual customer data, shared backend, or model evaluations. Its state is stored locally in the viewer’s browser and is not a secure production data store.

Internal demo acceptance is not buyer acceptance or evidence of model improvement.

## Potential software development

Future development could add sample upload and playback, shared episode metadata and verified permission records, authenticated reviewer roles, and an export validated against a buyer’s importer. Synchronization and robot-action schemas would require a capture setup that supplies those signals. These are software ideas, not completed capabilities or company milestones.
